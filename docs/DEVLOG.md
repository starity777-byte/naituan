# 奶团小屋 · 开发笔记

这里是奶团小屋各个模块的实现细节和设计记录。想先看看奶团、或者想一起建设，请回到 [README](../README.md)。

## 草图版前端（2026-09-29）

首页使用全屏房间。左上角爪爪展开「我的 / 游戏 / 小铺 / 图鉴 / 布置」；右上角三个圆环分别是喂小鱼、摸摸、睡觉。底部切换「窝 / 生活」。新存档自带星月阁楼、云朵地毯、月牙猫窝、望远镜，旧存档的房间、货币与收藏继续沿用。

前端基于线上仓库 `4b5a2ac` 整合，保留拖动抱起、耳朵 / 鼻尖 / 下巴 / 小爪触摸、长按蹭脸、家具探访与闲逛，以及家具缩放、镜像和方向微调。竖屏底图的墙根坐标随裁切换算；切换到生活或游戏页时停止房间行走。本机预览与 GitHub Pages 是不同网址，修改本地文件不会自动发布。

生活页包含单词打卡、饮食照片与文字记录，以及日历 / 待办 / 自习室专项。单词当天首次打卡得到 1 颗成长宝石，重复查看不重复领取；饮食照片在本机压缩保存。生活数据放在原存档的 `life` 字段里，和小屋进度一起导出 / 导入。

摸摸、蹭脸、抱起落地（DuangDuang 双弹跳 + 压扁回弹的 Q 弹形变）、喂食、睡醒、家具探访、堆纸箱（落箱、完美连击音阶、切边、掉落、新纪录）、小铺与存档操作、保存与打卡都有轻柔的短音效；摸头、耳朵、鼻尖、小爪、肚皮、尾巴各有几种不同的可爱叫声，连续快摸时音调会一路升高并在第 3、6、10 下加一声闪亮提示，使用 `sound.js` 在本机合成。首次互动后发声，闲逛不连续播放声音，切到后台停止当前声音。「我的 → 音效」统一控制小屋、生活页和小游戏，设置随存档保留。

这次的页面壳在 `house.css / house.js`，打卡与公共存档接口在 `life.js`，日历、自习室、按日期管理的待办在 `planner-state.js / planner.js / planner.css`。整体接口见 `FRONTEND-INTEGRATION.md`。

日历支持周 / 月与日期选择，待办支持新增、编辑、完成、改日期和删除撤销。自习室支持 15 / 25 / 50 分钟及自定义时长、关联待办、暂停继续、提前结束、刷新恢复和 5 分钟休息。记录使用本机浏览器存档，不自动跨设备同步。

## 窝的视角与布置

在窝里双指缩放（1～3 倍），放大后单指拖动背景移动视角；电脑可用滚轮或 ＋／− 按钮。「回正」恢复完整房间。拖动奶团可改变它的位置，松手保存。第二根手指落下时取消本次摸摸、长按蹭蹭或拖动，转为缩放，直到全部松手才接受新的奶团互动。

提起奶团时，淡淡的椭圆阴影留在地面标记落点，松手落回阴影处。落点越靠近墙根奶团越小，越靠近前方越大；四张手绘房间分别按自己的墙根计算。杏桃软软猫窝先试用同样的远近变化，仍能用大小滑条和镜像调整。

点「布置」后，可拖动窗户、地毯和当前摆出的饰品。下拉框也能选中被挡住的家具；选中后可用方向键微调。选中后用大小滑条或加减按钮调整到 50%～200%，可分别左右／上下镜像；方向按钮每次微调房间宽高的 1%。点「完成」保存，「取消」撤销本次调整，「重置单件」恢复选中家具的位置、大小和朝向。手机控件至少 44px 高。家具位置随存档导出／导入，旧存档沿用默认摆放。进入小游戏或小铺时会保存布置并恢复视角。

奶团脚底、家具中心及互动落点使用同一房间坐标；详见 [房间坐标约定](docs/room-coordinates.md)。本轮沿用现有布置入口，之后可把装修页面独立出去。

## 自己走路

点家具，奶团从当前位置走过去，抵达后再闻闻、踩奶或站在窗下观察。再点另一件家具会中途改道；互动结束留在原地。家具摆放或缩放后，目标使用新的实际落点。行走途中按地面远近连续变换大小，停步互动使用同一体型；经典房间基础宽度调整为 42%，让奶团和猫窝等家具的比例更协调，手绘大房间继续使用 34%。

停止操作约 9～18 秒后，奶团会走走停停，偶尔主动探访家具，或伸懒腰、玩纸箱、伸爪求牵。触摸、提起、双指操作会停止当前行走；睡觉、装修、小游戏、小铺、存档弹窗和页面隐藏时暂停。地面路线绕开独立落地家具的脚部，并按前后位置显示遮挡；画在房间底图里的物件暂不单独绕行。

`assets/animated/walk-side.webp` 和 `walk-front.webp` 来自提供的斜侧／正面行走素材，均为原始 503 × 402 透明四帧，每帧 140ms，无损循环 WebP。侧向行走随左右方向镜像，向前使用正面，向远处暂用斜侧。图片脚底用 CSS 对齐现有动作，切换时不再弹缩。

## 八套新动作

轻点耳朵会抖耳，碰鼻尖会眨眼张小圆嘴，挠下巴会抬头，点前爪可牵牵；长按脸颊约半秒开始蹭蹭，松手后再停留一小会儿。原有摸头、揉肚皮、碰尾巴仍保留。键盘聚焦奶团后：Enter／空格摸头，E 耳朵、N 鼻尖、C 下巴、P 牵爪、R 蹭蹭。

轻点经典或独立家具：走到窗下观察；走到地毯、床、窝、坐垫踩奶；走近其他家具闻闻。买下或换上家具后，回到房间会走向刚刚摆好的那件。行走和拖动共用保存的脚底坐标。房间底图中画死的窗户不单独响应点击。

八套均为 503 × 402、透明循环 WebP、两帧加轻微 CSS 形变，文件合计约 506 KiB。鼻尖采用选定的图二小圆嘴，踩奶采用 B 版浅趾痕圆爪。闲置时会伸爪求牵或观察周围。当前观察动画不包含起跳、爬窗和落地动作。

## 手绘装扮

小铺新增日式榻榻米、海边小屋、森林树屋、星月阁楼，共 64 件独立构件和 4 张空房底图，定价 100～3999 小鱼干。杏桃奶油屋和奶油绿田园另有 31 件，定价 100～500。商品缩略图即实际素材，点击可先预览，购买后在「布置」中拖动；各套构件可以混搭，也能收起来再摆出，不会重复收费。

底图与家具分别购买。手绘窗户／地毯摆出时隐藏经典窗户／地毯；使用经典窗户或地毯会回到经典房间，并收起对应手绘构件。旧商品与存档继续保留，构件位置同样随存档导出／导入。素材位于 `assets/decor/`，使用透明 WebP。

## 躲猫猫（节奏玩法）

跟着节拍，在奶团探出头的那一拍点它。速度从 84 BPM 慢慢加到 150 BPM，箱子从 3 个增加到 6 个、9 个。
灰色的纸片假猫是陷阱：点了掉一颗心；真猫溜走了也掉一颗心，5 颗心用完就结束。
评级看命中率（S/A/B/C），小鱼干按命中数和评级发放。声音是手机上现场合成的，不需要音频文件；简介页里可以关掉音效。
节奏参数（曲速、箱子增加的时机、假猫出现的概率）都在 `game.js` 里 `rhythm hide-and-seek` 那一段开头和 `genEvents` 里。

## 猫猫蛋糕店

排序小谜题：只能动每队最前面的一只猫，只能放进空队，或者放在同一种猫的前面（黑猫只能放在黑猫前面）。凑齐一队一样的猫，它们就进店买蛋糕，会分一块蛋糕角，可以收进图鉴或者卖掉换小鱼干。
猫从队尾往上排，空位留在队首那一头；猫的头像在 `assets/cats/`（8 种，奶团最稀有）。一共 15 关，越往后猫越多（最多 8 种）、每队越长（3 到 5 只）、队伍越多（最多 12 队），从第 3 关起只留 1 个空队。第 3 关起有**步数限制**（撤销不返还步数，超了就失败，可以「重来」），最后 5 关还有**短队**（有些队只能放 1～2 只）。最难的几关搜索量是第 1 关的十万倍以上。撤销一步花 2 个小鱼干；买走蛋糕之后不能撤销，没有能走的步时会提醒。
蛋糕稀有度取决于猫的稀有度和关卡：常见猫前期出金蛋糕的概率约 0.01%，后期约 1%。

**关卡怎么来的**：`tools/gen_levels.py` 先摆好通关状态，再倒着随机走若干步，所以一定有解；然后 `tools/solver.cpp`（A* 搜索）算出最少步数和搜索量（死路越多搜索量越大），用它们给关卡分难度、定步数上限（越往后上限离最少步数越近）、算星级（有限步的关卡：不超过最少步数的 1.12 倍是 3 星；无限步：1.3 倍是 3 星，2 倍以内是 2 星）。
重新生成关卡：

```bash
cd tools && g++ -O2 -std=c++17 -o solver solver.cpp && python3 gen_levels.py 21   # 约 2～3 小时（最难的几关搜索很慢）
```

猫头使用 `assets/cats/` 的手绘素材；8 款蛋糕切角使用 `assets/cakes/cake0-7.webp`，依次对应奶油、草莓、巧克力、抹茶、芒果慕斯、冰淇淋、银蛋糕、金蛋糕。奖励弹出、通关结算和蛋糕图鉴共用 `queue.js` 的 `cakeHTML`。图片替换保留原编号、掉落权重、售价和收藏进度。

## 存档

进度存在浏览器的 `localStorage`（键名 `naituan-house-v1`），每个网址、每台设备各存一份，不会自动同步。
爪爪菜单的「我的 → 存档：导出 / 导入」可以复制一串存档码，到另一台设备或另一个网址粘贴导入。

## 换素材

`game.js` 里的 `SPR` 表列出了每个动作用哪张图：

`sit` 坐着 · `happy` 开心 · `fish` 吃小鱼 · `cry` 哭 · `shy` 捂嘴笑 · `stretch` 伸懒腰 · `sleep` 睡觉 · `box` 玩纸箱 · `wave` 挥手 · `roll` 打滚笑 · `curious` 好奇 · `peek` 探头（`peekc` 是裁过边的探头，用在躲猫猫的箱子里）

房间和堆纸箱现在使用 `assets/animated/` 中的透明循环动画 WebP，原始 503 × 402 尺寸、帧数和播放速度均保留。该目录包含桌宠素材的全部 15 个动作；现有玩法使用眨眼、开心、吃小鱼、哭哭、偷笑、伸懒腰、睡觉、纸箱、挥手、打滚笑、好奇，其他动作暂时备用。睡觉使用真正蜷卧的「睡觉.webp」，叫醒后仍会伸懒腰。

日常互动：摸头开心、挠肚子打滚笑、碰右侧尾巴好奇，连续摸头会害羞；键盘 Enter / 空格仍可摸头。打开页面或离开页面至少一分钟再回来，清醒且没有正在进行的活动时挥手迎接。饱腹和心情都不低时，散步间也会穿插玩纸箱、伸懒腰、偷笑和伸爪，不连续重复同一个闲置动作；触摸、喂食等操作会重新计时。睡眠、装修、小游戏、装扮小铺和存档弹窗中不触发这些闲置动作。

新素材的脚在第 397 像素附近，房间布局和堆纸箱均按此对齐，避免拉伸或悬空。堆纸箱使用独立的图片层播放动画，纸箱运动和结算仍由原来的画布逻辑处理。躲猫猫继续使用原来的 `peekc.webp` 裁剪图，不改变判定或箱子布局。

旧的静态 WebP 保留在 `assets/` 中，方便回退。更新动画时直接替换对应文件，不要转换成单帧图片。
