# 房间坐标与互动点

房间左上角是 `(0, 0)`，右下角是 `(1, 1)`，x 向右、y 向下。所有存档坐标都相对完整房间，和手机分辨率、当前缩放倍数、视角平移无关。

## 保存的数据

| 对象 | 存档字段 | 坐标含义 |
| --- | --- | --- |
| 奶团 | `catPosition: {x, y}` | 图片底边中心，作为脚底落点 |
| 家具 | `roomLayout[key]: {x, y, scale, flipX, flipY}` | 家具矩形中心、尺寸比例和镜像；沿用已有格式 |
| 默认摆放 | `decor-catalog.js` 的 `x, y, w` | 中心坐标及相对房间宽度；高度由图片比例决定 |

家具 key 沿用 `win`、`rug`、`prop:<素材 id>`。旧存档没有 `catPosition` 时使用现有默认猫位；没有家具覆盖坐标时使用 CSS 或目录中的默认摆放。坐标跟随原有存档导出／导入，无需迁移旧存档。

## 家具互动点

每件家具可在目录中增加 `interactionAnchors`。它们是相对该家具矩形的比例，家具移动时自动跟随。

```js
interactionAnchors: {
  approach: { x: 0.5, y: 0.95 }, // 凑近观察、闻闻
  rest:     { x: 0.5, y: 0.68 }, // 坐下、踩奶
  watch:    { x: 0.5, y: 0.92 }  // 窗边观察
}
```

没有单独配置时使用以上默认值。家具放大、缩小或镜像后，落点跟随变换。家具图如果有明显留白，可针对素材修正落点。室内挂画等高处摆件的闻嗅落点会落在下方地面，避免猫悬空。

`NT.room.getItemGeometry(key)` 返回房间坐标下的 `center`、`size`、`anchors`；`NT.room.itemPoint(key, 'rest')` 直接取得某个互动落点。隐藏或未摆出的家具不提供互动点。底图画死的家具不作为独立对象。

## 奶团的位置与手势

- `NT.room.getCatPosition()`：当前实际脚底坐标。
- `NT.room.placeCat(point)`：临时移动；`placeCat(point, true)` 同时保存。
- `NT.room.placeCat(point, false, {surface: true})`：放到家具互动面上；使用调用者按家具算好的尺寸，并隐藏地面阴影。
- `NT.room.restoreCat()`：恢复已保存的位置或默认位置。
- `NT.room.cancelInteraction()`：取消尚未完成的触摸／拖动。

点击家具后步行到互动点，结束后留在原地。行走实时更新内存中的脚点，沿用定时存档，停步时再保存一次。拖动奶团在松手时保存新位置；取消事件或第二根手指按下会撤销本次拖动。视角缩放不会改变存档坐标。所有落点按猫的当前尺寸限制在房间内。

## 地面远近与提起

`floorBoundary` 用房间坐标的折线描述墙根。经典房间使用 `y = 0.63`；四张手绘底图分别在目录里标出墙根，按奶团当前 x 插值。地面落点限制在墙根稍下方到 `y = 0.985`，不会拖上墙面。

`NT.room.depthScale(point)` 按脚底到墙根的距离线性计算透视：墙根为基础尺寸的 56%，最前方为 104%。脚底坐标不随图片缩放而偏移。提起时只把奶团向上抬，独立的淡椭圆阴影留在落点；松手回落，双指取消时一起恢复原位。

家具先用 `peach-cat-bed`（杏桃软软猫窝）的 `depthAware: true` 试用相同透视，按猫窝底边计算远近。最终显示大小是「手动大小 × 透视比例」；存档里的 `scale` 仍然只保存手动值，镜像和互动点继续跟随实际显示尺寸。其余家具保持原有规则。

## 行走与停步

- `NT.room.groundPoint(point)`：约束到地面及当前体型可站立的边界。
- `NT.room.walkTo(point, onArrive, furnitureKey)`：沿地面路线走到脚点，抵达才调用回调；返回是否找到路线。目标家具允许进入，以便踩奶。
- `NT.room.stopWalk()`：停在当前脚点，废弃原目标回调。
- `NT.room.isWalking()`／`isInteracting()`：判断行走、拖动或双指操作，防止闲逛抢走触摸。

`walking.js` 在家具脚部矩形和墙根附近选择拐点，生成可见线段组成的短路线。落地家具按实际显示尺寸计算脚部，地毯、挂画和窗户不当作地面障碍。脚点在家具前后时按深度排序；踩奶时角色显示在该软垫之上。拖动、双指、睡觉、进入小铺／小游戏、页面隐藏会停步，不留下旧目标继续执行。

行走使用原有透视比例，步速也按远近变化；更换朝向或抵达家具不更改基础体型。经典房间基础宽度为 42%，手绘房间 34%，避免原来为了塞进家具而瞬间改变宽度。向前使用正面素材，左右及远处用斜侧；提供的素材尚无背面行走。窗户的落点是窗下地面，暂未加入爬窗或起跳动画。

后续独立装修界面可以继续写 `roomLayout`。底图中画死的物件没有独立几何信息，目前不参与寻路。
