# 小游戏收入（2026-10-18）

本次同步小红书版 1.2.0 的收入规则，商品价格、已有余额、已购装饰、照片、记录及存档键保持原样，不追溯补发历史奖励。

| 游戏 | 收入 |
| --- | --- |
| 合成大狮子 | 有得分时至少 1 条，每 10 分 1 条，另加本局最高合成等级奖励；随合成增量到账并保存，结算只补差额 |
| 堆纸箱 | 每层 4 条、每次完美额外 2 条、每 5 层额外 5 条 |
| 躲猫猫关卡 | 命中×2＋星数×5；首通保底 35/50/65/80/100，首次三星额外 20；中途退出只按命中计奖，不解锁下一关 |
| 躲猫猫无尽 | 命中×2＋完美数＋评级奖 S/A/B/C = 20/12/6/0，零命中为 0 |
| 蛋糕店常规 | 15＋关卡编号×5＋星数×5 |
| 蛋糕店挑战 | 原基础奖励×2＋星数×5；蛋糕售卖另算，价格不变 |

大狮子最高合成等级奖励从小橘猫到白虎依次为 `0,0,0,0,5,10,20,35,55,85,130,190,280`，只取本局达到的最高等级，不逐级重复叠加。例：1000 分／猎豹 135 条，3000 分／狮子 430 条，8000 分／白虎 1080 条。

`tools/verify-income.cjs` 验证大狮子真实合成即时到账与退出去重、重载保存、蛋糕店第一关完整通关、纸箱叠放和躲猫猫中途退出。运行方式与 `tools/verify-loading.cjs` 相同。躲猫猫规则、首次奖励与存档兼容性也由现有 Node 测试覆盖。
