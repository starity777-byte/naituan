# 奶团小屋

一个给手机玩的养成小游戏：喂小鱼、摸摸、让奶团钻纸箱睡觉，还有节奏版躲猫猫、堆纸箱和猫猫蛋糕店，玩游戏赚小鱼干，去装扮小铺给房间换墙纸、地毯、窗户和摆件。

纯静态页面，没有构建步骤，没有依赖。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 样式（颜色、字体都在最上面的变量里） |
| `game.js` | 状态、装扮小铺、节奏躲猫猫、堆纸箱、存档 |
| `queue.js` | 猫猫蛋糕店（排队买蛋糕）和蛋糕图鉴 |
| `levels.js` | 蛋糕店的 5 个关卡（由 `tools/gen_levels.py` 生成） |
| `tools/` | 关卡生成器和求最少步数的求解器（只在电脑上用，网页不需要） |
| `assets/` | 奶团图片（`*.webp`）和主屏幕图标 |
| `manifest.webmanifest` | 添加到手机主屏幕用 |

## 本地运行

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 躲猫猫（节奏玩法）

跟着节拍，在奶团探出头的那一拍点它。速度从 84 BPM 慢慢加到 150 BPM，箱子从 3 个增加到 6 个、9 个。
灰色的纸片假猫是陷阱：点了掉一颗心；真猫溜走了也掉一颗心，5 颗心用完就结束。
评级看命中率（S/A/B/C），小鱼干按命中数和评级发放。声音是手机上现场合成的，不需要音频文件；简介页里可以关掉音效。
节奏参数（曲速、箱子增加的时机、假猫出现的概率）都在 `game.js` 里 `rhythm hide-and-seek` 那一段开头和 `genEvents` 里。

## 猫猫蛋糕店

排序小谜题：只能动每队最前面的一只猫，放到别的队的队首。凑齐一队一样的猫，它们就进店买蛋糕，会分一块蛋糕角，可以收进图鉴或者卖掉换小鱼干。
一共 5 关，越往后猫越多、空位越少，最后一关每队 4 只。撤销一步花 2 个小鱼干；买走蛋糕之后不能撤销，可以「重来」。
蛋糕稀有度取决于猫的稀有度和关卡：常见猫前期出金蛋糕的概率约 0.01%，后期约 1%。

**关卡怎么来的**：`tools/gen_levels.py` 先摆好通关状态，再倒着随机走若干步，所以一定有解；然后 `tools/solver.cpp`（A* 搜索）算出最少步数，用它给关卡分难度、算星级。
重新生成关卡：

```bash
cd tools && g++ -O2 -std=c++17 -o solver solver.cpp && python3 gen_levels.py 11
```

猫和蛋糕现在都是占位的 SVG，在 `queue.js` 的 `catSVG` / `cakeSVG` 里，之后可以换成手绘图。

## 存档

进度存在浏览器的 `localStorage`（键名 `naituan-house-v1`），每个网址、每台设备各存一份，不会自动同步。
页面底部的「存档：导出 / 导入」可以复制一串存档码，到另一台设备或另一个网址粘贴导入。

## 换素材

`game.js` 里的 `SPR` 表列出了每个动作用哪张图：

`sit` 坐着 · `happy` 开心 · `fish` 吃小鱼 · `cry` 哭 · `shy` 捂嘴笑 · `stretch` 伸懒腰 · `box` 纸箱 · `peek` 探头（`peekc` 是裁过边的探头，用在躲猫猫的箱子里）

替换 `assets/` 里同名文件即可。图片需要是透明背景，奶团的脚大约在图片高度的 83% 处，这样所有动作站在同一条地线上。
