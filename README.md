# 奶团小屋

一个给手机玩的养成小游戏：喂小鱼、摸摸、让奶团蜷起来睡觉，还有节奏版躲猫猫、堆纸箱和猫猫蛋糕店，玩游戏赚小鱼干，去装扮小铺给房间换墙纸、地毯、窗户和摆件。

纯静态页面，没有构建步骤，没有依赖。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 样式（颜色、字体都在最上面的变量里） |
| `game.js` | 状态、装扮小铺、节奏躲猫猫、堆纸箱、存档 |
| `room.js` | 窝的缩放、拖动视角与家具摆放 |
| `queue.js` | 猫猫蛋糕店（排队买蛋糕）和蛋糕图鉴 |
| `levels.js` | 蛋糕店的 15 个关卡（由 `tools/gen_levels.py` 生成） |
| `tools/` | 关卡生成器和求最少步数的求解器（只在电脑上用，网页不需要） |
| `assets/` | 奶团图片（`*.webp`）和主屏幕图标 |
| `manifest.webmanifest` | 添加到手机主屏幕用 |

## 本地运行

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 窝的视角与布置

在窝里双指缩放（1～3 倍），放大后单指拖动画面；电脑可用滚轮或 ＋／− 按钮。「回正」恢复完整房间。轻点奶团仍可摸头、挠肚子和碰尾巴，拖动或双指操作不会触发摸猫。

点「布置」后，可拖动窗户、地毯和当前摆出的饰品。下拉框也能选中被挡住的家具；选中后可用方向键微调。点「完成」保存，「取消」撤销本次调整，「放回原位」复位选中的家具。家具位置随存档导出／导入，旧存档沿用默认摆放。进入小游戏或小铺时会保存布置并恢复视角。

## 躲猫猫（节奏玩法）

跟着节拍，在奶团探出头的那一拍点它。速度从 84 BPM 慢慢加到 150 BPM，箱子从 3 个增加到 6 个、9 个。
灰色的纸片假猫是陷阱：点了掉一颗心；真猫溜走了也掉一颗心，5 颗心用完就结束。
评级看命中率（S/A/B/C），小鱼干按命中数和评级发放。声音是手机上现场合成的，不需要音频文件；简介页里可以关掉音效。
节奏参数（曲速、箱子增加的时机、假猫出现的概率）都在 `game.js` 里 `rhythm hide-and-seek` 那一段开头和 `genEvents` 里。

## 猫猫蛋糕店

排序小谜题：只能动每队最前面的一只猫，只能放进空队，或者放在同一种猫的前面（黑猫只能放在黑猫前面）。凑齐一队一样的猫，它们就进店买蛋糕，会分一块蛋糕角，可以收进图鉴或者卖掉换小鱼干。
猫从队尾往上排，空位留在队首那一头；猫的头像在 `assets/cats/`（8 种，奶团最稀有）。一共 15 关，越往后猫越多（最多 8 种）、每队越长（3 到 5 只）、队伍越多（最多 12 队），从第 3 关起只留 1 个空队。第 3 关起有**步数限制**（撤销不返还步数，超了就失败，可以「重来」），最后 5 关还有**短队**（有些队只能放 1～2 只）。最难的几关搜索量是第 1 关的十万倍以上。撤销一步花 2 个小鱼干；买走蛋糕之后不能撤销，没有能走的步时会提醒。
蛋糕稀有度取决于猫的稀有度和关卡：常见猫前期出金蛋糕的概率约 0.01%，后期约 1%。

**关卡怎么来的**：`tools/gen_levels.py` 先摆好通关状态，再倒着随机走若干步，所以一定有解；然后 `tools/solver.cpp`（A* 搜索）算出最少步数和搜索量（死路越多搜索量越大），用它们给关卡分难度、定步数上限（越往后上限离最少步数越近）、算星级（有限步的关卡：不超过最少步数的 1.12 倍是 3 星；无限步：1.3 倍是 3 星，2 倍以内是 2 星）。
重新生成关卡：

```bash
cd tools && g++ -O2 -std=c++17 -o solver solver.cpp && python3 gen_levels.py 21   # 约 2～3 小时（最难的几关搜索很慢）
```

猫和蛋糕现在都是占位的 SVG，在 `queue.js` 的 `catSVG` / `cakeSVG` 里，之后可以换成手绘图。

## 存档

进度存在浏览器的 `localStorage`（键名 `naituan-house-v1`），每个网址、每台设备各存一份，不会自动同步。
页面底部的「存档：导出 / 导入」可以复制一串存档码，到另一台设备或另一个网址粘贴导入。

## 换素材

`game.js` 里的 `SPR` 表列出了每个动作用哪张图：

`sit` 坐着 · `happy` 开心 · `fish` 吃小鱼 · `cry` 哭 · `shy` 捂嘴笑 · `stretch` 伸懒腰 · `sleep` 睡觉 · `box` 玩纸箱 · `wave` 挥手 · `roll` 打滚笑 · `curious` 好奇 · `peek` 探头（`peekc` 是裁过边的探头，用在躲猫猫的箱子里）

房间和堆纸箱现在使用 `assets/animated/` 中的透明循环动画 WebP，原始 503 × 402 尺寸、帧数和播放速度均保留。该目录包含桌宠素材的全部 15 个动作；现有玩法使用眨眼、开心、吃小鱼、哭哭、偷笑、伸懒腰、睡觉、纸箱、挥手、打滚笑、好奇，其他动作暂时备用。睡觉使用真正蜷卧的「睡觉.webp」，叫醒后仍会伸懒腰。

日常互动：摸头开心、挠肚子打滚笑、碰右侧尾巴好奇，连续摸头会害羞；键盘 Enter / 空格仍可摸头。打开页面或离开页面至少一分钟再回来，清醒且没有正在进行的活动时挥手迎接。饱腹和心情都不低时，停止操作 25～45 秒后会随机玩纸箱、伸懒腰或偷笑，不连续重复同一个动作；触摸、喂食等操作会重新计时。睡眠、小游戏、装扮小铺和存档弹窗中不触发这些闲置动作。

新素材的脚在第 397 像素附近，房间布局和堆纸箱均按此对齐，避免拉伸或悬空。堆纸箱使用独立的图片层播放动画，纸箱运动和结算仍由原来的画布逻辑处理。躲猫猫继续使用原来的 `peekc.webp` 裁剪图，不改变判定或箱子布局。

旧的静态 WebP 保留在 `assets/` 中，方便回退。更新动画时直接替换对应文件，不要转换成单帧图片。
