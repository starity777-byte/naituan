# 奶团小屋

一个给手机玩的养成小游戏：喂小鱼、摸摸、让奶团钻纸箱睡觉，还有捉迷藏和堆纸箱，玩游戏赚小鱼干，去装扮小铺给房间换墙纸、地毯、窗户和摆件。

纯静态页面，没有构建步骤，没有依赖。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 样式（颜色、字体都在最上面的变量里） |
| `game.js` | 全部玩法：状态、装扮小铺、捉迷藏、堆纸箱、存档 |
| `assets/` | 奶团图片（`*.webp`）和主屏幕图标 |
| `manifest.webmanifest` | 添加到手机主屏幕用 |

## 本地运行

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 存档

进度存在浏览器的 `localStorage`（键名 `naituan-house-v1`），每个网址、每台设备各存一份，不会自动同步。
页面底部的「存档：导出 / 导入」可以复制一串存档码，到另一台设备或另一个网址粘贴导入。

## 换素材

`game.js` 里的 `SPR` 表列出了每个动作用哪张图：

`sit` 坐着 · `happy` 开心 · `fish` 吃小鱼 · `cry` 哭 · `shy` 捂嘴笑 · `stretch` 伸懒腰 · `box` 纸箱 · `peek` 探头（`peekc` 是裁过边的探头，用在捉迷藏的洞里）

替换 `assets/` 里同名文件即可。图片需要是透明背景，奶团的脚大约在图片高度的 83% 处，这样所有动作站在同一条地线上。
